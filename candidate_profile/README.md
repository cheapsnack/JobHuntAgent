# candidate_profile/

Your real facts. This folder is git-ignored — nothing here is committed.

| File | What goes in it |
|---|---|
| `<firstname>_base_resume.pdf` | Your current resume, as a PDF. The source of truth for every employer, title, date and metric. |
| `verified_facts.md` | Real facts not yet in the PDF — new certs, a metric you can now quantify, strong interview stories, current location, current/expected salary, notice period. Copy `verified_facts.example.md` to start. |
| `keyword_learnings.md` | Optional. ATS keyword notes you accumulate — which phrasings a JD used that you should mirror next time. |

**Rule for everything in here:** it must be true and defensible in an
interview. If you cannot back a number up, do not write it as a number —
write the qualitative version, or mark it `[estimate - verify before
sending]`.
